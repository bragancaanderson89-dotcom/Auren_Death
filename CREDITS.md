# Créditos

O estrondo `web/assets/pd-thunder.wav` é áudio original sintetizado para este resource, com impacto e reverberação de trovão, sem gravações externas.

- Resource, painel e integração: APEX.
- Modelo dourado fornecido no projeto: `golden_revolver.glb`.
- Modelo prateado fornecido no projeto: `revolver_navy_colt_1851_silver.glb`.
- Conversão: Blender, Sollumz, szio/pymateria.
- Imagens dos revólveres: renders dos modelos fornecidos.
- Imagens das munições: modelos e renders próprios preparados para este resource.
- Integração de servidor/inventário: QBOX, ox_lib, ox_inventory, oxmysql e ox_target.

As bibliotecas e programas de desenvolvimento não são redistribuídos neste resource. Os arquivos do jogo original utilizados como referência técnica não fazem parte do pacote.
